# رونق · رياضيات

الموقع: https://mayouni.github.io/rawnaq-ed/

رياضيات السنة السابعة من التعليم الأساسي (تونس)، باللمس والتجريب. عربيّة، بلا حساب، بلا إشهار، ولا شيء يغادر جهاز المتعلّم. يعمل بلا اتّصال بعد أوّل زيارة.

هذا المستودع هو الموقع المنشور وحده. التمارين مكتوبة على منوال الكتاب المدرسيّ الرسميّ بأعداد وكلمات مغايرة.

الخطّ Readex Pro برخصته (SIL OFL 1.1) في `fonts/OFL.txt`.
